# AI Automation Avanzado · Muebles Roble

Material de las clases del curso AI Automation Avanzado (Coderhouse). Todo el curso gira alrededor de un caso: **Muebles Roble**, una mueblería familiar de Córdoba que atiende consultas de clientes con un equipo de agentes en n8n.

| Carpeta | Qué tiene |

| `antes-de-la-clase-2.md` | Lo que tenés que tener listo antes de la Clase 2 (n8n, Groq y Slack) |
| `clase-02/inicio/` | Punto de partida: el agente del Módulo 1 aplicado al caso |
| `clase-02/pasos/paso-N/` | Cómo quedan los workflows después de cada paso de la clase |
| `clase-02/final/` | Los workflows completos de la clase |
